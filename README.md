# 摄像机·光锥揭画（Camera Beam Reveal）

零依赖纯 **HTML + SVG + JS** 动效组件，双击 `index.html` 即可在浏览器中实时预览、逐帧拖动和调参。

## 动效简介

- **开场抛接**：套色蓝墨摄像机机身从画面底部竖直上抛、空中翻滚一圈后自由落体回弹；随后起跳接住旋转落下的绿墨遮光罩。
- **光锥揭示**：机身与遮光罩撞击瞬间打出 36° 光锥，以 SVG `<clipPath>` 作为动态遮罩，照到哪里就露出哪里的 1 / 2 / 4 宫格画面，并伴随套印错版（misregistration）反馈。
- **五段卡点扫动**：底部 → 左侧 → 急蹿急停 → 右上甩扫 → 左中 → 右边缘停住，每段使用独立拟合的贝塞尔曲线，并附带基于位移/转角阈值的 2 层残影运动模糊。

## 快速预览

直接用浏览器打开 [index.html](./index.html) 即可查看配方卡、实时动画与参数面板。

### URL 参数

- `?embed=1`：隐藏左侧文档和控制栏，仅全屏显示舞台
- `?t=2.0`：定格在指定秒数
- `?p.scale=2.8&p.paperBg=1`：通过 URL 覆盖动效参数

### 快捷键

- `Space`：播放 / 暂停
- `←` / `→`：逐帧后退 / 前进（按住 `Shift` 步进 1 秒）
- `[` / `]`：减慢 / 加快播放速度
- `Home`：回到 0 秒

## 规格参数

| 项目 | 参数 |
|------|------|
| 分辨率 | 1920 × 1080 |
| 时长 | 4.8s |
| 默认配色 | 纸底 `#f3ead6` / 机身 `#2340c4` / 遮光罩 `#00a37a` |
| 核心架构 | 纯函数 `render(t, p, ctx)` + 零外部构建依赖 |

## 渲染 MP4（可选）

如果需要在本地将 HTML 逐帧渲染为 MP4（需要本机有 Chrome/Edge、`ffmpeg` 和 `puppeteer-core`）：

```bash
npm i -D puppeteer-core
node render.mjs --fps 60 --out out/camera-beam-reveal.mp4
```

```text
│   └── harness.css     # 预览界面样式
└── render.mjs          # 可选的无头浏览器逐帧渲染脚本
```
